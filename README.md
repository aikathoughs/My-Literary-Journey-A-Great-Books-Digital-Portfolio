# My Literary Journey — Great Books Digital Portfolio

> An interactive stationery-inspired digital portfolio created for the **Great Books** course (Great Books-GEC-GB-NRt) at the **University of Nueva Caceres**.

**Author:** Angelaica Mae P. Harochoc  
**Program:** Bachelor of Science in Information Technology (BSIT · 4th Year)  
**Institution:** University of Nueva Caceres · College of Computer Studies

---

## 📖 Overview

This portfolio showcases four major academic exhibits rendered inside a unified interactive **Literary Desk**:
1. **Compilation of Seven Literary Analyses (Great Books Hardcover)**: Critical analyses using Formalist, Psychological, Historical, and Archetypal lenses across seven world literary masterpieces.
2. **My Favorite Literary Masterpiece (Burgundy Notebook)**: A deep study and creative exploration of *Voice Out of the Whirlwind* (Job 38).
3. **Personal Reflection (Burnt-Orange Tabbed Notebook)**: Five thematic reflection categories with sticky notes and closing synthesis.
4. **Summary of Learning (Handheld Index-Card Stack)**: Key literary movements, critical lenses, and personal development takeaways.

## 🚀 Live Deployment on Vercel

This repository is optimized for instant static deployment on Vercel with zero configuration required. The entry point is [`index.html`](index.html).

### Deploying via Vercel CLI
```bash
npx vercel
```

### Deploying via GitHub + Vercel
1. Push this folder to a GitHub repository.
2. Import the repository into your [Vercel Dashboard](https://vercel.com/new).
3. Click **Deploy**. Vercel will automatically host the portfolio with a live `.vercel.app` domain.
